PSEUDOCODE: CURRENT REPOSITORY WORKFLOW

This document reflects the CURRENT folder layout and script responsibilities.

Folder naming convention:
- Figures are organized as `Figures/FigX/...` and panel-level folders such as `Fig3A`, `Fig4F`.
- Supplemental/extended figures are organized as `ExtendedFigures/SX`.
- Table workflows are organized as `Table6_MICOM`.
- Shared model resources are in `GENREs/GENREs/...`.
