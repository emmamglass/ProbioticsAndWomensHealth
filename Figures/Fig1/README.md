# Fig1 Analysis

This folder is named for the manuscript artifact it supports: `Fig1` corresponds to Figure 1 (panels A-C generated by this script/data).

This folder contains the code and data used to generate **Fig 1A, Fig 1B, and Fig 1C**.

## Standard README Template

- **Folder-to-manuscript mapping**: Folder name maps to the target figure/table/extended-data item.
- **Common section structure**: `Purpose`, `Scripts`, `Input Files`, `Output Files`, `Dependencies`, `Usage Notes`.

## Script

### `probioticsanalysis.py`
- Loads probiotic product metadata and binary species-presence data.
- Produces all three Figure 1 panels:
  - **Fig 1A**: boxplot of number of species by brand
  - **Fig 1B**: histogram of number of species across products
  - **Fig 1C**: PCA scatter plot of binary species presence, colored by general-use category

## Required Input File

- `BinarySpeciesPresence.csv`

## Notes

- The script displays figures with `plt.show()` and does not automatically save image files.
